py123detection.mmcv_export.tokens¶

What goes into info['token'].

123D stamps every frame with a deterministic UUID derived from (split, log_name, timestamp_us), which is enough for training but is not the nuScenes sample_token that the official nuScenes evaluation keys on. NuScenesTokenResolver restores those by joining on (log_name, timestamp_us). For datasets without native frame tokens, LogTimestampTokenResolver writes "{log_name}/{timestamp_us}", which an independent converter can reproduce.
