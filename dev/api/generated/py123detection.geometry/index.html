py123detection.geometry¶

SE(3) helpers shared by the export code.

123D poses and the mmdet3d info schema both use scalar-first quaternions, so the two map onto each other directly. Everything in between is plain 4x4 matrices.

py123detection.geometry.mmdet3d_yaw(rotation)[source]¶

Yaw as pyquaternion.Quaternion.yaw_pitch_roll[0], which mmdetection3d’s converter uses.

pyquaternion computes atan2(2(wz - xy), 1 - 2(y^2 + z^2)) where the textbook z-y-x yaw has +xy. Both agree for an upright box and drift apart with roll/pitch: a few milliradians in a lidar frame, but a large angle in a camera frame where the box lies on its side. Matching it keeps gt_boxes interchangeable with pickles from mmdetection3d’s own converter.

Return type:

float
