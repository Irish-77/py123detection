py123detection.torch.data.images¶

How a camera image becomes network input: one affine map, applied once.

Every step between the sensor and the network is an axis-aligned affine map of pixel coordinates: the rig’s fixed row crop and resize (rigs), the scale that makes the image cover the network input, the crop window, the horizontal flip. So the whole chain is one 3x3 matrix A, and it is used twice:

image_out  = warpAffine(image, A)     # one resampling of the source pixels
intrinsics = A @ intrinsics           # the camera that would have taken image_out

Because both come from the same matrix, pixels and projection cannot disagree. The thesis pipeline resized twice (to the rig’s size, then by the augmentation scale), which cost a second interpolation and left the intrinsics and the pixels a fraction of a pixel apart, because cv2.resize samples at pixel centres and the matrix scaled about the corner.

What is chosen per sample lives in ImageDraw, a zoom, a horizontal crop position and a flip, shared by every camera of the frame. ImagePipeline.resolve() turns a draw into the concrete transform for one camera’s size. The validation path is the default draw: no zoom, centred, not flipped.

matrix()[source]¶

The 3x3 map from the input’s pixel coordinates to the output’s.

Pixel centres sit on integer coordinates, so a window W pixels wide mirrors as x -> W - 1 - x, which is also what cv2.flip does. PETR mirrors as x -> W - x in the intrinsics while flipping the pixels with cv2.flip, which left every flipped camera’s projection one pixel off its image.

Return type:

ndarray

class py123detection.torch.data.images.ImagePipeline(size=(320, 800), mode='crop', pad_divisor=32)[source]¶

Bases: object

The network input every camera is mapped to.

Parameters:

mode (str) – "crop" scales by one factor until the image covers size, then cuts size out, bottom-aligned so the road is kept and the sky is lost. It keeps the pixel scale the same across cameras and is what PETR does. "stretch" resizes straight to size, distorting the aspect ratio but keeping the whole field of view; it ignores the zoom and the crop position of a draw.
